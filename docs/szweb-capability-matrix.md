# szweb capability matrix

This matrix maps capabilities from the existing blog to the szweb entry points. “Implemented” describes the source wiring; “verified” describes only the tests and local browser checks listed in the last column. Live mail delivery and remote OAuth are not inferred from local mocks or disabled integrations.

| Existing capability | New entry / component | Implementation status | Validation evidence and limits |
| --- | --- | --- | --- |
| Recent, pinned, and popular articles on Home | `/`; `pages/home.tsx`; existing recent/pinned/popular queries | Implemented. Featured article is first pinned or newest; remaining pins/popular items form the rail. Tags and view counts use existing queries. | Home is in the eight-width/39-view browser grid. The article cover map is currently empty; the type-led banner is intentional. |
| Article archive/list, date, summary, read time, tags, pinned/popular labels | `/posts`; `pages/posts.tsx`; `postsInfiniteQueryOptions` | Implemented. Starts with 12 and fetches cursor pages on demand. Filter state uses URL `tagName`; internal `_chroma:` topics are hidden. | In the browser grid. The current local fixture contains 25 published seed articles in ordinary mode; this is fixture data, not a product cap. |
| Per-article pageview counts | Home and Posts; `useViewCounts`, `useBatchedViewCounts`, `_shared/view-count-batches.ts` | Implemented. ## Overall verification state

The owner reports 137 unit tests across 11 files, three local guard checks, TypeScript, build, and lint passing (zero errors and three existing warnings). The stable strict browser run covered 40 views and 18 checks, all passing with zero errors and zero external requests. Sixteen interaction checks passed, including English, dark mode, and the mobile menu; a separate 12-check account report passed real profile, friend-link, logout, and admin-settings-save flows. `.local-dev/szweb-qa/product/report.json` passed 6/6 checks with zero errors and zero external requests for reading/TOC, code copy, and blank auth-form states. Supplemental checks covered search 503/retry, dark images, 404, and invalid-auth states. Six feed endpoints returned HTTP 200, four added routes appeared in the sitemap, reduced-motion checking observed no animation, and project keyboard/focus checks passed. The authenticated post-edit SSR mismatch was fixed with `ClientOnly`; final TypeScript and build checks passed.

The 24-check comments browser report also passed with zero errors and zero external requests. A separate `adminSettingsCheck` reports a Breadcrumbs hydration warning in an unmodified component; the baseline is unproven, so it is kept separate from the passing strict browser report. Local auth/mail/provider mocks are not evidence of live SMTP or remote OAuth success.
